# Forgeyard Workspace Agent Instructions

## Ignore Administrative & Meta Files During Software Development

When working on features, bug fixes, refactoring, or tests in this repository, **do NOT read or analyze meta/administrative files** unless explicitly requested by the user.

### Excluded Files (Default Ignore):
* `LICENSE` & `LICENSES/*`
* `MAINTAINERS.md`
* `GOVERNANCE.md`
* `CODE_OF_CONDUCT.md`
* `SECURITY.md`
* `CLA.md`
* `CONTRIBUTING.md`
* `CHANGELOG.md`
* `RELEASES.md`
* `ROADMAP.md`
* `typos.toml`, `.editorconfig`, `.gitattributes`, `.dockerignore`

Focus exclusively on technical implementation in `crates/`, `apps/`, `ecosystems/`, `protocols/`, `schemas/`, `tests/`, and related technical documentation unless explicitly told otherwise.
