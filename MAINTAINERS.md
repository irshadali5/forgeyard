## 2. Maintainer Responsibilities

Core maintainers are entrusted with the stewardship of the project and have write/admin permissions to the repository. Responsibilities include:

1. **Architecture & RFC Review**: Evaluating design proposals (`rfcs/`) for performance, security, hermeticity, and maintainability.
2. **Pull Request Triage & Merges**: Reviewing incoming contributions to ensure code quality, test coverage, clippy compliance, and CLA sign-offs.
3. **Release Engineering**: Signing and building canonical release binaries, container images, SDK crates, and security advisories.
4. **Licensing Enforcement & Enterprise Support**: Granting Commercial AGPL Exemptions, handling enterprise procurement, and delivering on-premises setup & SLA support for commercial clients.
5. **Community Health & Security**: Responding to security reports (`SECURITY.md`), enforcing the Code of Conduct (`CODE_OF_CONDUCT.md`), and triaging community issues.

---

## 3. Becoming a Maintainer

We welcome active contributors to join the maintainer team. Contributors who consistently demonstrate technical excellence, conduct constructive code reviews, participate in RFC discussions, and help triage issues can be nominated for maintainership by any existing core maintainer.
